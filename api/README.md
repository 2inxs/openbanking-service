# HTTP-контракты OpenBanking Service (MVP)

В этой директории зафиксированы контракты HTTP API для этапа MVP:

- **`api/openapi.yaml`** — внешний REST/JSON API основного сервиса (`cmd/api`).
- **`api/mockbank-openapi.yaml`** — подмножество банковского API (`cmd/mockbank`), используемое при ручной синхронизации счетов, остатков и операций.

## 1. Демонстрационный доступ и ограничения MVP

- **Фиксированный пользователь MVP:** в локальном MVP используется один демонстрационный пользователь из конфигурации сервера (`DEMO_USER_ID`). Клиент **не передаёт** произвольный `user_id` в query-параметрах, заголовках или теле запросов — владелец данных всегда определяется на сервере.
- **Отсутствие полноценной аутентификации:** регистрация, логин, JWT/OAuth2 и сессии в MVP не реализованы. Все запросы к `/api/v1/...` выполняются от имени демо-пользователя.
- **Доступ к Mock Bank:** используется статический `Bearer`-токен из переменной окружения `MOCKBANK_DEMO_TOKEN` (передаётся в заголовке `Authorization: Bearer <token>`). Интерактивный OAuth2 redirect flow и управление согласиями не входят в MVP.
- **Неподдерживаемые возможности MVP:** исходящие платежи и переводы (PIS), бюджеты, подписки, цели, push-уведомления и асинхронная очередь воркеров в MVP отсутствуют.
- **Соответствие стандартам:** основной API агрегатора (`/api/v1/...`) является собственным REST-контрактом приложения и **не претендует** на полное соответствие стандарту Open Banking Банка России. Подмножество стандарта ЦБ РФ v1.2.1 используется только для интеграции с `Mock Bank`.

## 2. Соглашения по форматам

| Тип данных | Формат | Пример |
| :--- | :--- | :--- |
| **Денежные суммы** | Десятичная строка с точкой (`float` запрещён). Для неизвестного остатка счёта — `null` | `"150050.00"`, `"-350.00"`, `null` |
| **Курсы валют** | Десятичная строка с 10 дробными знаками (рублей за 1 единицу валюты) | `"91.4567000000"` |
| **Коды валют** | ISO 4217 (3 заглавные латинские буквы) | `"RUB"`, `"USD"`, `"EUR"`, `"KZT"` |
| **Дата и время** | ISO 8601 / RFC 3339 (UTC или со смещением) | `"2026-11-20T09:15:00Z"` |
| **Календарная дата** | `YYYY-MM-DD` | `"2026-11-20"` |
| **Ошибки API** | JSON-объект `{ "code": "...", "message": "..." }` (опционально `fields`) | `{"code": "currency.rate_not_found", "message": "Курс не найден"}` |
| **Пагинация списка операций** | Keyset-пагинация по `(occurred_at DESC, id DESC)`: `cursor` + `limit` (`1..200`, по умолчанию `50`) | `?limit=50&cursor=...` |
| **Лимиты загрузок** | JSON-тело запроса — до `1 МБ`; файл выписки (CSV/XLSX) — до `10 МБ` и `100 000` строк | `multipart/form-data` |
