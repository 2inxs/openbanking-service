# Формат CSV-выписки (MVP)

Парсер в пакете `statement` принимает один строго зафиксированный формат CSV без автоопределения произвольных банковских выгрузок.

## Параметры файла

- **Кодировка:** `UTF-8` (допускается UTF-8 BOM в начале файла).
- **Разделитель колонок:** `;` (точка с запятой).
- **Десятичный разделитель:** `.` (точка), до 4 дробных знаков.
- **Ограничения:** до `10 МБ` и не более `100 000` строк операций (согласно `api/README.md`).
- **Первая строка:** обязательный заголовок из 7 колонок в фиксированном порядке.

## Структура колонок

| № | Колонка | Обязательность | Формат и правила |
|---|---|---|---|
| 1 | `account_number` | Обязательно | Номер счёта выписки. Должен быть одинаковым во всех строках файла. |
| 2 | `booked_at` | Обязательно | Дата проводки в формате `YYYY-MM-DD` или `RFC 3339` (приводится к UTC). |
| 3 | `amount` | Обязательно | Десятичная строка со знаком (`-350.00` — списание, `1500.50` — поступление; ноль запрещён). |
| 4 | `currency` | Обязательно | Код валюты ISO 4217 из 3 заглавных латинских букв (`RUB`, `USD`, `EUR`). Единый для всего файла. |
| 5 | `external_id` | Опционально | Внешний идентификатор операции в банке (может быть пустым). |
| 6 | `description` | Опционально | Назначение платежа (поддерживаются кавычки и переносы строк по RFC 4180). |
| 7 | `counterparty` | Опционально | Наименование контрагента или торговой точки. |
